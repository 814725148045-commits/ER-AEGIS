# ER-AEGIS: FastAPI Operational Intelligence Backend

## Overview

The ER-AEGIS backend is a high-performance Python FastAPI service providing operational emergency department analytics and ML-powered 60-minute congestion forecasting.

The backend directly interfaces with:
- `ml/model.joblib`: Serialized 300-estimator `RandomForestClassifier`
- `ml/feature_columns.json`: 28 validated operational features
- `data/hospital_data.csv`: Continuous 14-day 15-minute synthetic operational telemetry (1,344 rows)

> **DISCLAIMER:**
> This service is an operational hackathon prototype trained on synthetic hospital data. It is NOT clinically validated, must NOT be used for patient clinical triage or diagnosis, and is intended strictly for administrative and operational capacity management demonstration.

---

## Architecture & Reusability

- **Model Lifecycle**: The model is loaded **once** at server startup by `PredictionService` and retained in memory. It is **never** retrained on request.
- **Latency**: Sub-millisecond local inference per prediction query.
- **Data Validation**: Strict Pydantic schemas enforce bounds (e.g. non-negative counts, bed conservation, and maximum capacity limits).
- **CORS Support**: Configured for local development (`http://localhost:5173`, `http://localhost:3000`) and container preview environments.

## Installation & Setup

### 1. Requirements
Ensure Python 3.10+ is installed.
```bash
pip install -r backend/requirements.txt
```

### 2. Launching the Backend
Run Uvicorn from the project root:
```bash
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```
Or navigate to `backend/`:
```bash
cd backend
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

- **API Base URL**: `http://localhost:8000`
- **Interactive Swagger Documentation**: `http://localhost:8000/docs`
- **ReDoc Documentation**: `http://localhost:8000/redoc`

## API Endpoints

### 1. Health Check
`GET /api/health`
Verifies service status and confirms the ML model artifact is loaded.
```json
{
  "status": "ok",
  "service": "ER-AEGIS API",
  "model_loaded": true
}
```

### 2. Real-Time ML Prediction
`POST /api/predict`
Runs inference through the trained Random Forest model.
```json
// Request Body
{
  "patients_arrived": 8,
  "ambulance_arrivals": 2,
  "patients_waiting": 18,
  "patients_treated": 6,
  "beds_occupied": 58,
  "beds_available": 12,
  "doctors_available": 8,
  "nurses_available": 19,
  "support_staff_available": 7,
  "average_wait_time": 42.0,
  "average_treatment_time": 34.0,
  "admissions": 3,
  "discharges": 1,
  "arrival_rate_per_hour": 32.0,
  "treatment_rate_per_hour": 24.0,
  "bed_occupancy_rate": 0.829,
  "staff_capacity_score": 0.71,
  "congestion_score": 72.0
}
```
```json
// Response
{
  "congestion_probability": 0.87,
  "predicted_congestion": true,
  "risk_level": "CRITICAL",
  "prediction_horizon_minutes": 60
}
```

### 3. Current Dashboard Snapshot
`GET /api/dashboard`
Returns the latest available operational telemetry interval along with the immediate ML 60-minute prediction.

### 4. Historical Operational Telemetry
`GET /api/history?limit=96`
Chronological series of operational observations (e.g. 96 records = past 24 hours at 15-minute intervals).

### 5. 60-Minute Forecast
`GET /api/forecast`
Returns the genuine 60-minute forecast generated by the Random Forest model.

### 6. Resources Summary
`GET /api/resources`
Active acute bed counts and clinical provider allocations (doctors, nurses, support).

### 7. Operational Alerts
`GET /api/alerts`
Generates deterministic operational alerts (`HIGH_CONGESTION_RISK`, `LOW_BED_AVAILABILITY`, `HIGH_WAIT_TIME`, `STAFF_PRESSURE`) based on actual threshold violations.

### 8. Operational Recommendations
`GET /api/recommendations`
Actionable logistical suggestions with quantitative supporting evidence.

### 9. What-If Scenario Simulation
`POST /api/simulation`
Tests resource interventions (additional beds, nurses, doctors, arrival surge %) through the Random Forest model.
```json
// Request
{
  "additional_doctors": 2,
  "additional_nurses": 4,
  "additional_beds": 5,
  "arrival_increase_percent": 0
}
```
```json
// Response
{
  "baseline": {
    "congestion_probability": 0.82
  },
  "scenario": {
    "congestion_probability": 0.54
  },
  "change": {
    "probability_difference": -0.28
  },
  "assumptions": { ... }
}
```
